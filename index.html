REKOMENDASI · PWA

Install SmartStudy

Tambahkan aplikasi ke layar utama tanpa perlu membuka browser setiap kali. Pada perangkat yang mendukung, aplikasi dapat dibuka seperti aplikasi biasa.

Jika tombol belum tersedia, buka menu browser lalu pilih “Install app” atau “Tambahkan ke layar utama”. Gunakan alamat website HTTPS.

APK
ANDROID

File APK SmartStudy

SmartStudy dapat dipasang langsung di Android sebagai aplikasi PWA. Tidak perlu mengunduh APK dari situs lain.

Lihat cara install di Android ↓ Gunakan Chrome dan buka website melalui alamat HTTPS agar pemasangan tersedia.

Cara memasang langsung di Android

  1. Buka website SmartStudy melalui Chrome.
  2. Pastikan website menggunakan HTTPS.
  3. Tekan tombol Install Aplikasi pada halaman ini jika muncul.
  4. Jika tombol belum muncul, buka menu ⋮ Chrome lalu pilih Install aplikasi atau Tambahkan ke layar utama.
  5. Konfirmasi pemasangan. Ikon SmartStudy akan muncul di layar utama dan daftar aplikasi.
